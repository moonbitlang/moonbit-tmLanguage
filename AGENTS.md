# Contributor instructions

## Regression tests with snapshots

When a regression test uses a snapshot, split the change into three commits in this order:

1. Add the test and commit the snapshot generated by the current implementation. The test should pass and the snapshot should show the behavior that needs fixing.
2. Fix the implementation and keep the baseline snapshot. Run the test and check that the resulting diff shows the intended behavior change.
3. Review the diff, update the affected snapshot, and rerun the test to confirm it passes.
